# 콘텐츠 출처

## Decisions

- 앱이 자동으로 가져오거나 가공해 보여주는 콘텐츠는 이용 조건이 공개된 자료만 출처로 쓴다. 영어 표현은 Wiktionary(CC BY-SA)와 Tatoeba(CC BY 2.0 FR)를 기본 후보로 한다.
- 공개 자료를 쓸 때는 출처와 라이선스를 화면에 표시하고, 라이선스가 요구하는 조건(Wiktionary는 동일 조건 공유)을 지킨다.
- 네이버 블로그, EBS 방송과 교재 내용, Urban Dictionary는 블로거나 권리자의 허락 또는 확인된 공식 이용 조건이 생기기 전까지 수집하거나 가공하지 않는다.

## Boundaries

- 사용자가 직접 입력한 개인 기록과 사용자가 쓴 일기는 이 결정의 대상이 아니다.
- 원문 링크를 거는 것은 수집이 아니므로 제한하지 않는다.
- 이 결정은 건강 정보와 추가 관심사의 출처를 정하지 않는다. 그 출처는 같은 기준으로 따로 고른다.

## Why

처음 목표였던 네이버 블로그 자동 수집은 허용되는 경로가 없었다. 블로그와 RSS 호스트의 robots.txt가 크롤러를 막고 있고, 방송 표현의 원저작권은 EBS에 있다. 네이버 검색 API는 개발자 센터의 신규 발급이 끝났고, 개정 약관은 데이터를 원문 그대로 보여주는 용도만 허용하는 것으로 보도되었다. 표현을 뽑아 퀴즈와 복습으로 가공하는 이 앱의 용도와 맞지 않는다. 가공이 허용되는 공개 라이선스 자료를 쓰면 이 제약이 사라진다.

## Reconsider when

- 블로거나 EBS가 앱의 용도에 대해 서면으로 허락할 때
- 네이버 API HUB의 이용 약관 원문이 요약 저장과 가공을 허용한다고 확인될 때

## Still-rejected alternatives

- 네이버 검색 API(개발자 센터) — 신규 키 발급이 2026년 7월 31일에 끝났다. 새 경로인 NAVER API HUB는 유료 전환 예정이고 개정 약관상 가공이 막힐 가능성이 높다. 약관 원문을 확인하면 다시 검토한다.
- 블로그 RSS와 본문 크롤링 — 두 호스트의 robots.txt가 크롤러를 막고, 블로그 글의 저작권은 작성자에게 있다. 허락이 있으면 다시 검토한다.
- Urban Dictionary — 공식 API와 이용 조건을 확인하지 못했고 Kaggle의 CC0 표시는 올린 사람의 주장일 뿐이다. 공식 이용 조건이 확인되면 다시 검토한다.

## Evidence worth preserving

- Wiktionary 원본(wiktextract 전체 언어 JSONL, 압축 약 2.8GB)에서 영어 항목 중 slang으로 표시된 뜻은 약 34,000개였다.
- 비속어, 모욕, 구식, 희귀, 약어를 빼고 인용이 아닌 짧은 예문이 있는 뜻은 약 3,400개, 그중 미국 표기가 붙은 것은 447개였다.
- 걸러낸 목록에는 지역적이거나 낯선 단어, 예문이 아닌 문장("Near-synonym: ..."), 부자연스러운 뜻이 섞여 있어 사람이 검수해야 한다.
- 위 수치와 표본은 데이터 판 기준(2026년 9월 2일 덤프)이며 다시 받으면 달라질 수 있다.
