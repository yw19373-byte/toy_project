# 오늘의 slang 보기

## 사용자 결과

앱을 열면 오늘의 slang 3개가 보입니다. 각 Slang 항목에는 표현, 영어 정의, 한국어 번역, 예문, 출처가 함께 나옵니다. 같은 날에는 몇 번을 열어도 같은 3개가 나오고, 날짜가 바뀌면 다른 3개가 나옵니다.

## 승인된 범위

- 앱의 첫 화면에 오늘의 slang 3개를 보여줍니다.
- Slang 항목 하나는 다음을 함께 보여줍니다.
  - 표현
  - 영어 정의(공개 자료의 원문)
  - 한국어 번역(이 작업에서 직접 작성)
  - 예문
  - 출처와 라이선스 표시(원문 링크 포함)
- 검수 모음은 앱에 포함되어 배포되며, 사용자가 입력하거나 외부에서 받아오지 않습니다.
- 첫 화면은 폰 화면 폭에서 정보 순서가 유지되어야 합니다.

## 인수 기준

1. 폰 크기의 화면에서 앱을 열면 Slang 항목이 정확히 3개 보인다.
2. 각 항목에 표현, 영어 정의, 한국어 번역, 예문이 모두 있고 비어 있는 칸이 없다.
3. 각 항목에서 출처(Wiktionary의 해당 문서)로 이동하는 링크가 열린다. 화면에 라이선스(CC BY-SA)가 표시된다.
4. 같은 날 새로고침하거나 다시 열어도 같은 3개가 같은 순서로 나온다.
5. 날짜를 하루 바꿔서 확인하면 이전 날과 겹치지 않는 3개가 나온다. 날짜를 바꿔 확인할 수단이 있어야 한다.
6. 검수 모음에 비속어, 모욕 표현, 구식 표현이 없다. 모든 항목의 예문은 정의와 맞는 완결된 문장이다.
7. 로딩, 오류, 모음이 비었을 때의 화면이 정상 화면과 같은 구성 문법으로 표시된다.

## 확정된 제약과 이유

- 앱 전체 제약은 [PRODUCT.md](../../../PRODUCT.md)를 따른다. 이 작업에 해당하는 것은 폰에서 쉽게 열고 닫을 수 있어야 한다는 원칙과 오늘의 slang 3개를 하루 단위로 받는다는 약속이다.
- 콘텐츠는 이용 조건이 공개된 자료에서만 가져온다. 출처와 라이선스를 반드시 표시한다. 근거와 거절된 대안은 [content-sources](../../decisions/content-sources.md)가 정한다.
- UI는 shadcn 구성과 하나의 시각 언어를 따른다. 구체적인 규칙은 [ui-composition](../../decisions/ui-composition.md)이 정한다.
- 정의는 영어 원문, 번역은 한국어로 함께 보여준다. 영어 공부 앱이라 정의만으로는 이해가 어려운 사용자가 있고, 번역이 있어야 이후 퀴즈와 복습의 기반이 된다.
- 한국어 번역은 원 자료와 별개로 작성한 창작이므로 라이선스 부담이 없다.

## 가정(바꿀 수 있음)

- 검수 모음의 초기 크기는 60개입니다. 3개씩 20일치입니다.
- 날짜는 기기의 현재 날짜를 기준으로 하고, 하루는 기기의 자정에 바뀝니다.
- 오늘의 3개는 날짜에서 결정되는 순서로 검수 모음을 돌며 고릅니다. 모음의 끝에 도달하면 처음으로 돌아갑니다. 이 순환은 복습 기능이 생기기 전까지의 임시 동작입니다(복습 간격 기능이 정해지면 그 결정으로 대체).
- 비속어는 제외하되, 일상 대화에서 흔한 가벼운 slang은 포함합니다. 경계가 애매한 항목은 제외하는 쪽을 택합니다.
- 검수 모음은 Wiktionary에서 걸러낸 미국 표기 slang 후보(약 447개) 중에서 고릅니다. 후보에 없는 흔한 slang을 쓰려면 Wiktionary 항목과 라이선스 확인이 선행되어야 합니다.
- 예문은 Wiktionary 항목의 예문 중 인용문이 아닌 짧은 문장을 씁니다.

## 범위 밖과 이유

- 건강 콘텐츠, 추가 관심사, 관심사 추가와 삭제: 이 작업의 사용자 결과와 별개이고 출처가 아직 정해지지 않았다.
- 복습 퀴즈와 복습 간격: 오늘의 slang이 먼저 동작해야 복습할 대상이 생긴다.
- 알림과 알림 시각 설정, 일기, 일기 기반 추천, 지인 공유: 핵심 루프의 뒤 단계다.
- 로그인과 사용자별 저장: 이번 결과는 사용자 데이터가 필요 없다.
- 네이버 블로그, EBS 방송 내용, Urban Dictionary 수집: [content-sources](../../decisions/content-sources.md)가 막고 있다.
- 새 slang의 자동 수집과 모음 자동 확장: 사람이 검수해야 하는 상태이므로 후속 작업이다.

## 미룬 결정

- 건강 정보와 추가 관심사의 출처: 같은 기준(공개 라이선스, 출처 표시)으로 따로 정한다.
- 복습 간격의 구체적인 일수와 알고리즘: 복습 작업 단위에서 정한다.
- 검수 모음을 60개 이후 어떻게 늘릴지: 첫 결과를 쓰며 부족을 느낄 때 정한다.

## 남은 위험

- 후보의 품질이 고르지 않아 사람의 검수가 필요하다. 검수 품질이 낮으면 틀린 정의나 어색한 예문이 앱에 들어간다.
- Wiktionary의 CC BY-SA 동일 조건 공유 의무가 검수 모음과 앱에 어디까지 적용되는지는 법률 검토를 하지 않았다.
- 한국어 번역과 정의가 일치하는지, 비속어 경계가 맞는지는 사용자가 직접 훑어봐야 확인된다.
- 사용 자료의 라이선스 원문은 이 환경에서 직접 읽지 못했다.
